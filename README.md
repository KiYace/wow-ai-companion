# Azeroth Companion

AI-компаньон для World of Warcraft 3.3.5a.

Проект исследует возможность создания игрового питомца, который способен наблюдать за происходящим в игре, поддерживать собственное состояние и память, разговаривать с игроком и реагировать на игровые события в реальном времени.

## Возможности

На текущем этапе проект находится в разработке.

Планируемые возможности:

* получение игровых событий из WoW Addon;
* обработка событий на Go backend;
* диалог с AI-компаньоном;
* долговременная память питомца;
* состояние и характер компаньона;
* голосовое взаимодействие;
* realtime-коммуникация между игрой и backend;
* расширение контекста AI информацией об игровом мире.

## Технологический стек

* **Go** — backend
* **Lua** — World of Warcraft Addon
* **PostgreSQL** — хранение состояния и памяти
* **Docker / Docker Compose** — окружение и запуск сервисов
* **OpenAI API** — AI и голосовые возможности

## Цели проекта

Проект создаётся не только как эксперимент с AI, но и как практический проект для изучения Go и backend-разработки.

В процессе разработки планируется изучить и применить:

* Go modules;
* HTTP API;
* interfaces;
* dependency injection;
* `context.Context`;
* goroutines и channels;
* конкурентную обработку событий;
* работу с PostgreSQL;
* transactions;
* migrations;
* WebSocket;
* интеграцию с внешними API;
* обработку ошибок, timeout и retry;
* structured logging;
* unit и integration tests;
* Docker;
* CI/CD;
* observability.

## Статус

🚧 Проект находится на ранней стадии разработки.

Первый этап — минимальный Go backend, способный принимать HTTP-запросы и отвечать на них.
